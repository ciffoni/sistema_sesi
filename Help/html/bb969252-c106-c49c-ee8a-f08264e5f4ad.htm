      conexao Class

      Gerencia a conexão com o banco de dados MySQL para a aplicação. Esta classe é responsável por fornecer uma instância de conexão e gerenciar seu estado.

      Remarks

      Os parâmetros de conexão (servidor, banco, usuário, senha) são definidos como estáticos dentro da classe. Certifique-se de que estas credenciais estejam seguras e não expostas em ambientes de produção. Considere usar configurações externas (ex: App.config) para ambientes de produção.
